# مكتب آفاق الإنجاز العقاري

نظام متكامل لإدارة العقارات مع بوت تيليجرام ذكي وموقع ويب احترافي.

## المميزات

- ✅ 30 عقار حقيقي (10 في كل قسم)
- ✅ بوت تيليجرام ذكي مع لوحة تحكم
- ✅ معالجة صور وفيديو بالذكاء الاصطناعي
- ✅ خريطة تفاعلية 3D
- ✅ مساعد ذكي يتحدث السعودية
- ✅ تحديث أخباري تلقائي يومي
- ✅ SEO متقدم
- ✅ قاعدة بيانات MongoDB

## التثبيت

```bash
npm install
```

## التشغيل

```bash
npm start
```

## نشر البيانات الأولية

```bash
npm run seed
```
